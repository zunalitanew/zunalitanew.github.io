About Zunalita

Zunalita is an independent place to publish ideas, reflections, and writing from the community.

How it works

The website is a static GitHub Pages site. It gets story filenames from the public posts archive, then loads a story only when you open it. There are no accounts or server-side features on this site.

Privacy

The site does not use analytics or ask for personal information. Your reading list, text-size preference, and unfinished editor draft are stored in this browser only. Your browser connects to GitHub to list and open stories; GitHub receives normal connection data. Linked images and websites may also load from their own hosts.

Contribute

Use the story editor to preview and download a Markdown draft, then submit it to the open posts archive as a pull request. The editor does not request GitHub credentials.

Contact

Questions and discussion: GitHub Discussions. For archive issues, visit the posts repository.
